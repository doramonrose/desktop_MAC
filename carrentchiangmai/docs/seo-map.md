## Link flow
- หน้าแรก → ประเภทรถ, ราคา, airport, tours, policy, FAQ
- Vehicle → ราคา + airport/ทริปที่เหมาะ + policy
- Tour → tours hub + ราคา + policy + quote
- ราคา → vehicle ทุกประเภท + quote
- ทุกหน้า → contact, privacy, booking policy ผ่าน footer
- BreadcrumbList สะท้อน hierarchy จริง; ไม่มี doorway page หรือ tag/archive URL
