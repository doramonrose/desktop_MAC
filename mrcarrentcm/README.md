# MR Car Rent Chiang Mai

เว็บไซต์บริการรถเช่าพร้อมคนขับเชียงใหม่  
โดเมนเป้าหมาย: [mrcarrentcm.com](https://mrcarrentcm.com)

## Run locally

**ต้องใช้ Node.js 20+**

```bash
cd mrcarrentcm
npm install
npm run dev
```

เปิด http://localhost:3000

## Scripts

- `npm run dev` — รันเซิร์ฟเวอร์พัฒนา (Express + Vite)
- `npm run build` — build production
- `npm start` — รัน production จาก `dist/`
- `npm run lint` — ตรวจ TypeScript
