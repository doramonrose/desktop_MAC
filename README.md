## เพิ่มโปรเจกต์ใหม่

สร้างโฟลเดอร์ใหม่ใน root เช่น `project-name/` แล้วใส่โค้ดของโปรเจกต์นั้นไว้ข้างใน

```text
desktop_MAC/
├── README.md
├── mrcarrentcm/
└── your-new-project/
```
